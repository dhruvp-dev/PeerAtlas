# Peeratlas

Welcome to the Peeratlas monorepo. This repository contains both the web frontend (Next.js) and the upcoming Python OCR services.

## Repository Structure

- **/web**: Contains the Next.js frontend application.
- **/ocr**: Reserved for the upcoming Python-based OCR service.


## Getting Started

### Web (Next.js)
Navigate to the `web/` directory to start the frontend:
```bash
cd web
npm install
npm run dev
```

### OCR (Python)
Navigate to the `ocr/` directory to set up the Python service:
```bash
cd ocr
python -m venv .venv
source .venv/bin/activate
# Add and install requirements as needed
```

## Version Control
Git has been initialized in this repository. Ensure that any local outputs or sensitive environment variables remain ignored by git.
